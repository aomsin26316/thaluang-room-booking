# ระบบจองห้องประชุมออนไลน์ (Online Meeting Room Reservation System)
### วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์

ระบบเว็บแอปพลิเคชันจองห้องประชุมออนไลน์ ออกแบบและพัฒนาขึ้นโดยอ้างอิงโครงสร้างข้อมูลและกระบวนการตาม **แบบฟอร์มขออนุญาตใช้ห้องประชุมทางการ** ของวิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์ รองรับการเชื่อมต่อฐานข้อมูลแบบเรียลไทม์กับ **Google Sheets** และระบบแจ้งเตือนผ่าน **LINE Notify**

---

## 🏛️ ข้อมูลและฟิลด์ในระบบ (อ้างอิงแบบฟอร์มทางการ)

1. **ข้อมูลผู้ขออนุญาต**:
   - ชื่อ-นามสกุล, ตำแหน่ง, หน่วยงาน/สาขาวิชา, เบอร์โทรศัพท์ติดต่อ
2. **รายละเอียดการขอใช้**:
   - หัวข้อ/เรื่องในการดำเนินงาน, จำนวนผู้เข้าใช้ (โดยประมาณ)
3. **ห้องประชุมที่ให้บริการ**:
   - หอประชุมอดิเรกสาร
   - ห้องประชุมสักทอง
   - ห้องประชุม (กาแฟ)
   - อาคารโดมเอนกประสงค์
   - ห้องประชุมหน้าห้องผู้อำนวยการ
   - ห้องคอมพิวเตอร์กลาง (ห้องโสต)
   - อื่นๆ (ระบุเพิ่มเติมได้)
4. **วันและเวลา**:
   - วันที่เริ่มต้น - สิ้นสุด, ตั้งแต่เวลา - ถึงเวลา
5. **ขอใช้อุปกรณ์/ครุภัณฑ์**:
   - เครื่องฉายภาพ (Projector), ระบบเสียง, ไมโครโฟน, เครื่องปรับอากาศ, อินเทอร์เน็ต (Wi-Fi), โต๊ะ/เก้าอี้เพิ่มเติม, และอุปกรณ์อื่นๆ เพิ่มเติม
6. **กระบวนการพิจารณาอนุมัติ (Approval Workflow)**:
   - **สถานะเริ่มต้น**: `รอตรวจสอบ`
   - **ขั้นตอนที่ ๑**: เจ้าหน้าที่งานศูนย์ดิจิทัลและสื่อสารองค์กร (ตรวจสอบความพร้อมของห้องและอุปกรณ์ -> เปลี่ยนสถานะเป็น `พร้อมใช้งาน` / `ไม่พร้อมใช้งาน` หรือ `รออนุมัติ`)
   - **ขั้นตอนที่ ๒**: รองผู้อำนวยการฝ่ายพัฒนายุทธศาสตร์และแผนงาน (พิจารณาผลการอนุมัติ -> `อนุมัติแล้ว` หรือ `ไม่อนุมัติ`)

### ขั้นตอนการตั้งค่า Google Apps Script (ทำเพียงครั้งเดียว):

1. เปิดสเปรดชีตข้างต้นใน Google Drive ของท่าน
2. ไปที่เมนูด้านบน คลิก **ส่วนขยาย (Extensions)** ➔ **Apps Script**
3. ลบโค้ดเดิมในหน้าต่างออกทั้งหมด แล้วคัดลอกเนื้อหาจากไฟล์ `google-apps-script/Code.gs` วางลงไปแทนที่
4. กดบันทึก (รูปไอคอนแผ่นดิสก์ หรือ `Ctrl + S`)
5. กดปุ่มสีน้ำเงินด้านบนขวา **"ทำให้ใช้งานได้" (Deploy)** ➔ **"การทำให้ใช้งานได้รายการใหม่" (New deployment)**
6. คลิกที่รูปเฟืองด้านซ้าย เลือกประเภท **"เว็บแอปพลิเคชัน" (Web app)**
7. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description):** API จองห้องประชุม วท.ท่าหลวง
   - **เรียกใช้ในฐานะ (Execute as):** **ฉัน (Me)**
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** **ทุกคน (Anyone)** *(สำคัญมาก เพื่อให้หน้าเว็บส่งคำขอได้)*
8. คลิก **"ทำให้ใช้งานได้" (Deploy)** และยืนยันการอนุญาตสิทธิ์ (Authorize access) ให้เรียบร้อย
9. คัดลอก **URL เว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec`
10. เปิดหน้าเว็บแอป คลิกปุ่ม **"ตั้งค่าระบบ / API"** ที่มุมขวาบน นำ URL มาวางในช่อง Google Apps Script URL แล้วกดบันทึก

> 💡 **หมายเหตุ:** ระบบมี LocalStorage Fallback ในตัว หากยังไม่ได้เชื่อมต่อ Apps Script เว็บจะยังคงทำงาน บันทึกข้อมูล ตรวจสอบ และอนุมัติได้ปกติในเบราว์เซอร์ทันที!

## 📲 วิธีเปิดใช้งานการแจ้งเตือน LINE Notify (ไม่บังคับ)

1. เข้าไปที่ [https://notify-bot.line.me/](https://notify-bot.line.me/) แล้วเข้าสู่ระบบ
2. ไปที่หน้า My Page แล้วกด **Generate token (ออก Token)**
3. ตั้งชื่อ Token เช่น `ห้องประชุม วท.ท่าหลวง` และเลือกกลุ่ม LINE ที่ต้องการให้แจ้งเตือน
4. นำ Token ที่ได้ ไปใส่ในช่อง **LINE Notify Token** ในเมนู "ตั้งค่าระบบ / API" ของเว็บ

## 🌟 ฟังก์ชันเด่นในระบบ

1. **ระบบตรวจจับการจองซ้ำซ้อน (Conflict Detection)**: แจ้งเตือนทันทีหากช่วงเวลาและห้องประชุมที่ต้องการ มีผู้ได้รับการอนุมัติหรือยื่นจองไว้ก่อนแล้ว
2. **ปฏิทินอัจฉริยะ (Interactive Calendar)**: มุมมองรายเดือน รายสัปดาห์ รายวัน พร้อมจำแนกสีตามห้องประชุมแต่ละห้อง
3. **ระบบอนุมัติ 2 ขั้นตอน (Two-Tier Approval Workflow)**: แยกหน้าจออย่างชัดเจนระหว่างการตรวจความพร้อมด้านไอที/ระบบเสียง และการลงนามอนุมัติของผู้บริหาร
4. **พิมพ์แบบฟอร์มขออนุญาตทางการ (Print Official Slip)**: จัดรูปแบบตามแบบฟอร์มเอกสารราชการของวิทยาลัย พร้อมช่องบันทึกความเห็นและลายเซ็น 2 ฝ่าย สามารถสั่งพิมพ์หรือบันทึกเป็น PDF ได้ทันที
5. **ระบบสรุปสถิติและส่งออก Excel (Reports & XLSX)**: กราฟสรุปจำนวนการใช้แต่ละห้องและสัดส่วนอุปกรณ์ พร้อมปุ่ม Export เป็น Excel ครบถ้วนทุกคอลัมน์
