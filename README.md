# 🏛️ ระบบจองห้องประชุมออนไลน์ (Smart Meeting Room Booking System)
### เทมเพลตมาตรฐานสำหรับสถานศึกษาและหน่วยงานราชการ (White-Label Template)

ระบบเว็บแอปพลิเคชันจองห้องประชุมออนไลน์ที่เชื่อมต่อกับ **Google Workspace (Google Sheets, Google Drive, Google Calendar)** แบบครบวงจร ออกแบบและพัฒนาขึ้นตาม **แบบฟอร์มขออนุญาตใช้ห้องประชุมทางการ** รองรับการออกเอกสารคำขอขนาด **A4 PDF** บันทึกจัดเก็บลง Google Drive อัตโนมัติ พร้อมระบบการอนุมัติ 4 ลำดับขั้น และการลงคิว Google Calendar อัตโนมัติ

---

## 🌟 คุณสมบัติเด่นของระบบ (Key Features)

1. **Auto-Setup Database (ติดตั้งฐานข้อมูลอัตโนมัติ)**:
   - ตรวจสอบและสร้างชีต `Bookings` (28 คอลัมน์) และ `Settings` พร้อมลงข้อมูลตัวอย่างและจัดรูปแบบอัตโนมัติ
2. **การออกเอกสารคำขอ A4 PDF ลง Google Drive อัตโนมัติ**:
   - เมื่อมีการส่งคำขอ ระบบจะแปลงข้อมูลเป็นเอกสารราชการขนาด A4 พร้อมตราสัญลักษณ์สถาบันและตารางลงนาม
   - แปลงเป็นไฟล์ PDF และจัดเก็บลงโฟลเดอร์ Google Drive พร้อมตั้งสิทธิ์แชร์ให้อัตโนมัติ
   - คืนค่าลิงก์ `PDF_Drive_URL` กลับมาบันทึกใน Google Sheets และแสดงปุ่มเปิดดูบนหน้าเว็บทันที
3. **White-Label Template (นำไปใช้กับสถาบันอื่นได้ทันที)**:
   - ปรับเปลี่ยนชื่อสถานศึกษา, โลโก้, รายชื่อห้องประชุม และรายชื่อผู้บริหารได้โดยตรงในชีตแท็บ `Settings` หรือหน้าต่างตั้งค่า โดยไม่ต้องแตะต้องโค้ดแม้แต่บรรทัดเดียว
4. **กระบวนการอนุมัติ 4 ลำดับขั้น (Approval Workflow)**:
   - **ผู้ขออนุญาต**: ส่งคำขอและเลือกอุปกรณ์/จำนวนเก้าอี้
   - **เจ้าหน้าที่งานศูนย์ดิจิทัลฯ (Inspector)**: ตรวจสอบความพร้อมของห้องและอุปกรณ์
   - **หัวหน้างาน/หัวหน้าแผนก (Supervisor)**: ให้ความเห็นชอบตามลำดับขั้น
   - **ผู้บริหาร/รอง ผอ. (Approver)**: พิจารณาอนุมัติคำขอ
5. **Google Calendar Auto-Sync**:
   - เมื่อผู้บริหารกด "อนุมัติ" ระบบจะนำกำหนดการไปลงคิวใน Google Calendar ของวิทยาลัยให้อัตโนมัติ ป้องกันการจองซ้ำซ้อน
6. **การแจ้งเตือนแบบ Multi-Channel**:
   - แจ้งเตือนเข้ากลุ่ม **Telegram** (พร้อมลิงก์ PDF คำขอ) และ **LINE Notify** แบบเรียลไทม์
7. **สถิติและการส่งออก Excel (Reports & Export)**:
   - กราฟสรุปจำนวนครั้งการใช้แต่ละห้องและสัดส่วนอุปกรณ์ (Chart.js)
   - ส่งออกข้อมูลทุกคอลัมน์เป็นไฟล์ `.xlsx` (Excel) ได้ทันที

## 📋 โครงสร้างฐานข้อมูลชีต `Bookings` (28 คอลัมน์)

| 8 | `RoomOther` | ห้องอื่นๆ (กรณีระบุเพิ่มเติม) |

| 10 | `StartDate` | วันที่เริ่มต้น (YYYY-MM-DD) |
| 11 | `EndDate` | วันที่สิ้นสุด (YYYY-MM-DD) |
| 12 | `StartTime` | ตั้งแต่เวลา (HH:mm) |

| 23 | `SupervisorDate` | วันเวลาที่หัวหน้างานพิจารณา |
| 24 | `ApproverStatus` | ผลการพิจารณาของผู้มีอำนาจ (`อนุมัติ` / `ไม่อนุมัติ`) |

| 26 | `ApproverDate` | วันเวลาที่อนุมัติ |

| 28 | `PDF_Drive_URL` | ลิงก์ดาวน์โหลดเอกสาร PDF คำขอใน Google Drive |

## ⚙️ การตั้งค่าศูนย์กลางในชีต `Settings` (White-Label Config)

| คีย์ตัวแปร (Key) | ค่าตัวอย่าง (Value) | คำอธิบายการปรับแต่ง |
|:---|:---|:---|
| `COLLEGE_NAME` | วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์ | ชื่อสถานศึกษา/หน่วยงานของท่าน |
| `COLLEGE_LOGO_URL` | https://.../logo.png | URL รูปภาพตราสัญลักษณ์สถาบัน |
| `DRIVE_FOLDER_ID` | *(เว้นว่างไว้ได้)* | รหัสโฟลเดอร์ Google Drive เก็บไฟล์ PDF (ถ้าว่าง ระบบจะสร้างให้อัตโนมัติ) |
| `CALENDAR_ID` | `primary` | รหัส Google Calendar สำหรับลงคิว (ใช้ `primary` สำหรับปฏิทินหลัก) |
| `TELEGRAM_BOT_TOKEN` | `123456:ABC-DEF...` | โทเค็น Telegram Bot สำหรับแจ้งเตือน |
| `TELEGRAM_CHAT_ID` | `-100123456789` | Chat ID กลุ่มหรือบุคคลรับแจ้งเตือน Telegram |
| `LINE_NOTIFY_TOKEN` | *(เว้นว่างได้)* | โทเค็น LINE Notify สำหรับแจ้งเตือนเข้าห้องไลน์ |
| `ROOM_LIST` | หอประชุมอดิเรกสาร,ห้องประชุมสักทอง,... | รายชื่อห้องประชุม คั่นด้วยเครื่องหมายจุลภาค (,) |
| `INSPECTOR_TITLE` | เจ้าหน้าที่งานศูนย์ดิจิทัลและสื่อสารองค์กร | ตำแหน่งผู้ตรวจความพร้อมห้อง/อุปกรณ์ |
| `SUPERVISOR_TITLE` | หัวหน้างานบริหารงานทั่วไป | ตำแหน่งหัวหน้างานผู้กำกับดูแล |
| `APPROVER_TITLE` | รองผู้อำนวยการฝ่ายพัฒนายุทธศาสตร์และแผนงาน | ตำแหน่งผู้บริหารผู้มีอำนาจอนุมัติ |

## 📖 คู่มือการติดตั้งและนำไปใช้ต่อ (Distribution Guide สำหรับสถานศึกษาอื่น)

> 💡 **สำหรับครูหรือผู้ดูแลระบบที่ไม่เชี่ยวชาญด้านโค้ด**: ทำตามขั้นตอน 1–5 ด้านล่าง ใช้เวลาไม่เกิน 5 นาที ระบบจะพร้อมใช้งานทันที!

### ขั้นตอนที่ 1: เตรียม Google Spreadsheet
1. สร้าง Google Sheet เปล่าขึ้นมา 1 ไฟล์ใน Google Drive ของท่าน หรือเปิดไฟล์ต้นฉบับ
2. ไปที่เมนูด้านบน คลิก **ส่วนขยาย (Extensions)** ➔ **Apps Script**

### ขั้นตอนที่ 2: ติดตั้งโค้ด Backend
1. ลบโค้ดเดิมในหน้าต่าง `Code.gs` ออกทั้งหมด
2. คัดลอกโค้ดทั้งหมดจากไฟล์ [`google-apps-script/Code.gs`](google-apps-script/Code.gs) ไปวาง
3. กดปุ่ม **บันทึก (Save)** หรือกด `Ctrl + S`
4. ที่แถบเครื่องมือด้านบน ในช่องเลือกฟังก์ชัน ให้เลือกฟังก์ชัน **`setupDatabase`** แล้วกดปุ่ม **เรียกใช้ (Run)**
5. กดยอมรับสิทธิ์การเข้าถึง (Review Permissions ➔ เลือกบัญชี Google ➔ Advanced ➔ Go to ... (unsafe) ➔ Allow)
6. สเปรดชีตของท่านจะถูกสร้างแท็บ `Bookings` และ `Settings` พร้อมใช้งานทันที!

### ขั้นตอนที่ 3: ปรับแต่งข้อมูลสถานศึกษา (White-Label)
1. กลับมาที่หน้าต่าง Google Sheets คลิกที่แท็บ **Settings**
2. แก้ไขค่าในคอลัมน์ `Value` เช่น:
   - เปลี่ยน `COLLEGE_NAME` เป็นชื่อโรงเรียน/วิทยาลัยของท่าน
   - ใส่ `COLLEGE_LOGO_URL` เป็นลิงก์รูปตราโรงเรียนของท่าน
   - แก้ไข `ROOM_LIST` เป็นห้องประชุมที่มีจริงในสถาบันของท่าน

### ขั้นตอนที่ 4: เผยแพร่เว็บแอปพลิเคชัน (Deploy as Web App)
1. ในหน้าต่าง Apps Script คลิกปุ่มสีน้ำเงินด้านขวาบน **"ทำให้ใช้งานได้" (Deploy)** ➔ **"การทำให้ใช้งานได้รายการใหม่" (New deployment)**
2. คลิกรูปฟันเฟืองด้านซ้าย เลือกประเภท **"เว็บแอปพลิเคชัน" (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description):** `ระบบจองห้องประชุมออนไลน์ v2`
   - **เรียกใช้ในฐานะ (Execute as):** **ฉัน (Me)**
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** **ทุกคน (Anyone)** *(สำคัญมาก เพื่อให้หน้าเว็บส่งและรับข้อมูลได้)*
4. คลิก **"ทำให้ใช้งานได้" (Deploy)**
5. คัดลอก **URL เว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec`

### ขั้นตอนที่ 5: ใช้งานเว็บแอปพลิเคชัน
- **กรณีใช้งานผ่าน GitHub Pages / เว็บภายนอก**:  
  เปิดหน้าเว็บ คลิกปุ่ม **"ตั้งค่าระบบ / White-Label"** ที่มุมขวาบน นำ Web App URL มาวางในช่อง แล้วกดบันทึก
- **กรณีใช้งานผ่าน Apps Script URL โดยตรง**:  
  สามารถส่งลิงก์ Web App URL ให้ครูและบุคลากรเปิดใช้งานได้ทันที

## 📱 การตั้งค่าแจ้งเตือน Telegram Bot (ไม่บังคับ)

1. ค้นหาบอท `@BotFather` ใน Telegram แล้วพิมพ์ `/newbot` เพื่อสร้างบอทใหม่
2. นำ **Bot Token** ที่ได้มาใส่ในช่อง `TELEGRAM_BOT_TOKEN` ในชีต Settings
3. เชิญบอทเข้ากลุ่มที่ต้องการรับแจ้งเตือน แล้วนำ **Chat ID** ของกลุ่มมาใส่ในช่อง `TELEGRAM_CHAT_ID`
4. ทุกครั้งที่มีการจองหรืออนุมัติ บอทจะส่งข้อความแจ้งเตือนพร้อมลิงก์เปิดดู PDF บน Google Drive ทันที!

## 💻 วิธีการรันในเครื่องคอมพิวเตอร์ (Local Server)

- **วิธีที่ 1 (แนะนำบน Windows)**: ดับเบิลคลิกที่ไฟล์ `start-app.bat` ระบบจะเปิดเบราว์เซอร์ไปยัง `http://localhost:8000` อัตโนมัติ
- **วิธีที่ 2 (คำสั่งไพทอน)**:
  ```bash
  python server.py
  ```
- **วิธีที่ 3**: ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานใน Google Chrome หรือ Microsoft Edge ได้ทันที
